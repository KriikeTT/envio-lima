# Formulario de envío Lima – Luxury Skincar's

Formulario para clientes de Lima Metropolitana y Callao: DNI (nombre automático desde RENIEC), celular,
Boleta o Factura (RUC validado en SUNAT y placa), distrito, dirección, referencia y el botón
"Usar mi ubicación actual" (GPS del celular). Los datos llegan por WhatsApp con el link de Google Maps.

Publicado en https://lima.luxuryskincars.com (GitHub Pages). Se edita directamente `index.html`.
